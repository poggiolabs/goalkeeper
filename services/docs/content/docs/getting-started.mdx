---

## Prerequisites

- Bun 1.3 or newer
- Docker with Compose

## Installation

```bash
bun install
cp .env.example .env
```

## Development

Start PostgreSQL and all four application services:

```bash
bun run dev
```

To work on one component, use `bun run web:dev`, `bun run api:dev`,
`bun run auth:dev`, or `bun run docs:dev`.

## Validation

```bash
bun run check
```
